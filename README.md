# Improve Knowledge — Backend Interview Prep (Middle, English interview, 2027)

Kho học tập cá nhân để chuẩn bị nhảy việc vị trí **Middle Backend Developer (Java)** tại công ty lớn, phỏng vấn bằng tiếng Anh, mục tiêu **đầu năm 2027**.

**Xuất phát điểm:** Backend Game (C++/Java, gRPC, Redis, MySQL) + Spring Boot (GM Tool, dự án cá nhân FPM). Tiếng Anh giao tiếp hằng ngày được, phỏng vấn còn thiếu từ và thiếu tự tin.
